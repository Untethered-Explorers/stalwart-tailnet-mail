A private mail server for this tailnet, installed by one script

Long image

A

Answer

Everything is prepared in ~/projects/email; one command installs, configures and verifies it: sudo bash install-mail.sh.

  1. The installer keeps OpenSMTPD and Dovecot bound to 127.0.0.1 and the Tailscale address, never to a public interface.
  2. Both daemons authenticate system accounts through PAM, so the installer ships the two PAM service files Ubuntu omits.
  3. Tailscale issues the TLS certificate and a weekly timer renews it before the 90-day expiry.
  4. The run ends with live checks: local delivery, TLS on three ports, SMTP AUTH and an IMAP login.

Applies toUbuntu 26.04Dovecot 2.4.2OpenSMTPD 7.8tailnet-only

1

What carries a message from an agent to a mailbox?

Two paths share one store: clients submit through OpenSMTPD, and read directly from Dovecot.

Diagram structure
  • Mail client human
  • Agent client agent
  • OpenSMTPD smtpd
  • Dovecot dovecot
  • Maildir maildir
  • human → smtpd · submit, 465/587
  • human → dovecot · read, 993
  • agent → smtpd · submit, 465/587
  • agent → dovecot · read, 993
  • smtpd → dovecot · LMTP
  • dovecot → maildir · store

Delivery is Dovecot's job even though OpenSMTPD receives the message: OpenSMTPD hands each envelope to Dovecot over the LMTP socket, so the Maildir is indexed on arrival.

What does the installer do, in order?

Diagram structure
  • Check tailnet pre
  • Install daemons pkg
  • Issue certificate cert
  • Create agent account users
  • Render configs conf
  • Validate syntax check
  • Start services start
  • Verify end to end verify
  • cert → users
  • check → start · valid
  • conf → check
  • pkg → cert
  • pre → pkg
  • start → verify
  • users → conf

It validates before it restarts anything: smtpd -n and doveconf -n run first, so a bad config never reaches a running service.

  1. Check tailnet ↗

    Confirms MagicDNS, the HTTPS certificate capability and the 100.x address; stops with a fix if HTTPS certs are off.

  2. Install daemons ↗

    Installs OpenSMTPD, Dovecot core, IMAP and LMTP packages.

  3. Issue certificate ↗

    Writes mail.crt and mail.key under /etc/ssl/tailscale, key mode 0600.

  4. Create agent account ↗

    Creates agent-bot with a nologin shell and a generated password in /root/mail-credentials.txt.

  5. Render configs ↗

    Renders /etc/smtpd.conf, /etc/dovecot/dovecot.conf, both PAM files and the renewal timer.

  6. Validate syntax ↗

    Runs both daemons' own config parsers before touching the running services.

  7. Start services ↗

    Enables and restarts Dovecot first, then OpenSMTPD, after tailscaled.

  8. Verify end to end ↗

    Sends a real message and checks TLS, SMTP AUTH and IMAP login.
