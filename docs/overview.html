A private mail server for your tailnet, installed by one script

Long image

A

Answer

One command installs a real mail server that only your Tailscale devices can reach. Stalwart serves SMTP, IMAP and HTTPS, Bulwark Lite provides the webmail, and Tailscale issues a certificate clients already trust.

  1. Stalwart runs the mail protocols and serves the webmail from the same origin, so there is no second web server to run.
  2. Tailscale issues the certificate and a weekly timer renews it through Stalwart's API.
  3. Every listener binds to loopback and the 100.x address; there is no public exposure.
  4. Accounts log in with the full address, and each agent gets its own account plus app password.

Applies toDebian or Ubuntu hostTailscale tailnet with HTTPS certificatesno internet mail

1

What talks to what?

The browser never touches IMAP. It loads the webmail from Stalwart on 443, and the webmail talks JMAP to the same origin. Agents skip the browser and speak SMTP and IMAP directly.

Diagram structure
  • Browser browser
  • Agent script agent
  • Stalwart stalwart
  • Data store store
  • browser → stalwart · https 443
  • agent → stalwart · smtp 465, imap 993
  • stalwart → store · mail and settings

The data store holds messages, accounts, certificates and settings. It is the only thing to back up.

What does the installer do?

Diagram structure

  • Install Stalwart pkg
  • Bootstrap config boot
  • Recovery mode rec
  • Install certificate cert
  • Create listeners lis
  • Create accounts acc
  • Mount webmail web
  • Activate services act
  • Verify chk
  • acc → web
  • act → chk
  • boot → rec
  • cert → lis
  • lis → acc
  • pkg → boot
  • pre → pkg
  • rec → cert
  • web → act

It confirms the tailnet first, installs Stalwart, and only then touches the ports.

  1. Check tailnet ↗

    Confirms MagicDNS, the HTTPS certificate capability and free ports; stops with the exact fix otherwise.

  2. Install Stalwart ↗

    Downloads the official release and the matching CLI; records the version.

  3. Bootstrap config ↗

    Pins an administrator, then writes hostname, domain and storage through the Bootstrap API. No wizard needed.

  4. Recovery mode ↗

    Runs the management API on loopback with mail listeners stopped, so configuration cannot collide with a running server.

  5. Install certificate ↗

    Fetches the Tailscale certificate and stores it as a Stalwart Certificate object.

  6. Create listeners ↗

    Creates 25/465/587/993/443 bound to loopback and the tailnet address.

  7. Create accounts ↗

    Creates the human and agent accounts with generated passwords, saved before anything else can fail.

  8. Mount webmail ↗

    Adds Bulwark Lite as an Application and triggers its download.

  9. Activate services ↗

    Leaves recovery mode, stops any old MTA, starts Stalwart on the real ports.

  10. Verify ↗

    Checks listeners, TLS, IMAP login and the webmail endpoint.
